Scenarios: p1, p6, p7
--------------------------------------------------------------------------------
Tests: 

First test: 
    * P1 - no policies
    * P6 - Set all nuclear to 0 (PJM, NJ, and NY) and keep al other resources as is. ESR Set to 1.0
    * P7 - Set all nuclear to 0 (PJM, NJ, and NY) and keep al other resources as is. ESR set to 0.7
